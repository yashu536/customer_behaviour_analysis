## 8. How to Run

Follow these steps to reproduce the project:

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Data-Analytics-Project
   ```

3. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Load the dataset and execute the Python notebooks in sequence.

6. Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server.

7. Execute the SQL scripts to perform database analysis.

8. Open the Power BI `.pbix` file to explore the interactive dashboard.

9. Review the final project report and Gamma AI presentation.
